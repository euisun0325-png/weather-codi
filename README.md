# 날씨코디 (WeatherCodi) v0.2 — 안드로이드 MVP

내 옷장과 전신사진, 그리고 내일 날씨로 **전날 저녁에 내일 코디(옷과 신발)를 알려주는** 앱입니다.

## 실행 방법
1. 압축을 풀고 **Android Studio**에서 `File > Open` → `WeatherCodi` 폴더를 선택합니다.
2. Gradle Sync가 끝나면 휴대폰을 USB로 연결하고 ▶ Run을 누릅니다. (안드로이드 8.0 이상)
3. 첫 실행 때 **알림 권한을 허용**해 주세요.

## 처음 설정 (설정 탭)
| 항목 | 설명 |
|---|---|
| Gemini API 키 | https://aistudio.google.com/apikey 에서 무료로 발급받습니다. 키가 있으면 옷 사진만 찍어도 종류, 색, 두께, 격식이 자동으로 채워지고, AI가 전신사진을 참고해 코디를 골라줍니다. |
| 기상청 키 (선택) | 공공데이터포털에서 ‘기상청_단기예보 조회서비스’를 활용신청한 뒤 **일반 인증키(Decoding)**를 넣습니다. 키가 없으면 Open-Meteo(무료, 키 불필요) 날씨를 씁니다. |
| 위치 | ‘현재 위치로 설정’을 누르면 기상청 격자 좌표로 자동 변환됩니다. 기본 위치는 서울입니다. |
| 알림 시각 | 오후 5시~11시 중에서 고릅니다. 기본값은 밤 9시입니다. |
| 전신사진 | AI가 체형에 맞는 코디를 고를 때 참고합니다. |

> 모든 사진과 옷장 정보는 **휴대폰 안에만** 저장됩니다. AI 기능을 쓸 때만 사진이 Gemini로 전송됩니다.

## 동작 방식
- **옷장 탭:** ＋ 옷 추가 → 카메라/갤러리 → (AI 자동 태그) → 저장 순서로 등록합니다.
- **매일 알림 시각:** 내일 예보를 받아 규칙 엔진이 1차로 추천하고, Gemini 키가 있으면 AI가 다듬은 뒤 알림을 보냅니다.
- **규칙 엔진:** 평균기온을 기준으로 바람이 강하면 -2℃, 비나 눈이 오면 -1℃로 체감온도를 보정하고, 이에 맞는 두께(1~5)를 정합니다.
  - 일교차가 10℃ 이상이면 얇은 겉옷을 추가합니다.
  - 비나 눈이 오면 방수 신발을 우선합니다.
  - 최근 1~3일 안에 입은 옷은 덜 추천합니다.
  - 격식과 색 조화도 점수로 반영합니다.
- **보관 위치:** 옷마다 장롱, 서랍, 리빙박스 같은 위치를 적어둡니다. 추천 화면과 알림에 📍 위치가 함께 표시되고, 옷장 탭에서는 장소별로 걸러 볼 수 있습니다.
  - ‘계절 보관 중 📦’을 켜둔 옷이 추천되면 "오늘 밤 미리 꺼내두세요"라는 팁이 나옵니다.
  - ‘이걸로 입을게요’를 누르면 보관 중 표시가 자동으로 해제됩니다.
- **‘이걸로 입을게요’:** 누르면 착용 기록이 저장되어 같은 옷이 연속으로 추천되지 않습니다.
- **🛍️ 부족한 옷:** 날씨에 맞는 옷이 옷장에 없으면 네이버쇼핑 검색으로 연결합니다.

## 파일 구조
```
app/src/main/java/com/woongpapa/weathercodi/
 ├ data/      Models.kt(옷·예보·추천), Repository.kt(저장·사진·설정)
 ├ weather/   WeatherService.kt(기상청 + Open-Meteo, 격자 변환)
 ├ ai/        GeminiClient.kt(사진 자동 태그, AI 코디)
 ├ engine/    OutfitEngine.kt(규칙 기반 추천)
 ├ work/      Planner.kt(추천 생성, 알림, 매일 예약)
 └ ui/        Main/Home/Wardrobe/Settings 화면 (Jetpack Compose)
```

## 다음 단계(2단계) 예정

- 아침에 예보가 바뀌면 수정 알림
- 추천 결과에 👍/👎를 받아 취향 학습
- 전신사진에 추천 코디를 입혀 보는 가상 착장
